
# LexMind – Automação Inteligente

A LexMind é uma empresa criada com apoio de Inteligência Artificial Generativa,
focada em transformar processos empresariais em resultados mensuráveis por meio
de automação inteligente.

## 🧐 Processo de Criação
O cliente que tem um empreendimento de automação com n8n nos procurou para executar os seguintes serviços:
- Criação do nome da empresa
- Criação da logomarca
- Criação de apresentação instutucional
- Website Institucional

## 🚀 O que este projeto demonstra
- Uso de IA Generativa para criação de marca
- Engenharia de prompts aplicada a negócios
- Automações com IA
- Site institucional
- Apresentação executiva

## 🧠 Tecnologias e Ferramentas
- IA Generativa (ChatGPT)
- Gamma App
- Nicepage 
- HTML / CSS / JS

## 📂 Estrutura
O repositório está organizado por etapas do projeto, desde a concepção até a entrega final.

## 📌 Objetivo
Demonstrar domínio técnico, estratégico e criativo no uso de IA aplicada a negócios reais.

## 🚀 Resultados
O cliente ficou extremamente satisfeito com o resultado final

## 💭 Reflexão (Opcional)
